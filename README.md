# 质检表自动生成·归档·打印 一体化工具

把「读 Excel → 填质检表 → 重命名 → 归档 → 打印」整条流程一键跑完。

## 两种使用方式

### 方式一：桌面图形界面（推荐，现代深色界面）

双击 `质检表工具.exe` 即可，无需安装任何环境，直接打开图形界面（无黑色命令行窗口）。界面操作：

1. **数据源（首次使用时手动选择一次，程序自动记住）**：
   - **工作跟进表**：点「选择...」选 Excel 文件
   - **质检表模板**：点「选择...」选空模板 docx
   - **归档目录**：点「选择...」选订单管理根目录
   - 选择结果自动保存到个人目录 `~/.qc_tool_config.json`，下次打开自动载入 —— **换电脑、换人使用都无需改任何文件**
2. **模型名称**：输入患者名，多个用空格 / 逗号分隔（如 `聂梓瑜 马睿杰 方馨悦 张梓菡`）；**同名患者有多次订单时，程序会弹出订单列表让您人工选择本次要生成质检表的订单**；
3. **打印机**：自动加载本机打印机列表，下拉选择
4. **每份张数**：默认 2
5. **打印开关**：打开则打印，关闭则只生成归档
6. 点 **开始执行**，下方实时显示运行日志，完成后显示归档结果

源码：`qc_gui.py`（基于 customtkinter，重新打包命令见文件头部注释）。

### 方式二：命令行

```
python qc_pipeline.py --names 聂梓瑜 马睿杰 方馨悦 张梓菡
python qc_pipeline.py          # 不传 --names 时提示手动输入模型名称
python qc_pipeline.py --list-printers
```

## 环境要求

- Windows + 已安装 **Microsoft Word**（打印功能依赖 Word COM；仅生成归档不需要）
- 命令行方式需 Python 3.8+：`pip install python-docx openpyxl`（GUI 版还需 `customtkinter`）

## 程序做的事（对应手动流程）

1. **读 Excel**：从「订单跟踪」表按「数据名称」匹配患者，取出订单编号、客户名称、材料批次号、机器编号、理论重量、实际重量；
2. **生成质检表**：复制空模板，填入模型名称、线材批次、打印设备、理论/实际重量（格式与刘佳利示例一致）；检测项勾选、质检人、日期因 Excel 无数据而留空；
3. **命名**：`订单编号-患者名.docx`；
4. **归档**：移动到 `交复侧弯订单管理/<客户名称>/<订单编号>/`，目录不存在自动创建，同订单重复运行会覆盖旧文件；**售后订单（Excel 订单类型="售后订单"）自动归档到 `交复侧弯订单管理/0售后件/<客户名称>/<订单编号>/`**；
5. **打印**：逐份调用 Word 打印到指定打印机（失败自动重试 3 次），中文路径走 UTF-8 临时文件避免乱码。

## 自定义路径

**图形界面**：三个路径（Excel / 模板 / 归档目录）在界面上点「选择...」即可，选完自动记住，无需改任何文件。

**命令行**：默认路径在 `qc_pipeline.py` 开头 `DEFAULT_*` 常量中；也可用 `--excel / --template / --base-dir / --printer / --copies` 临时指定。
